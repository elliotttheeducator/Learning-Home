Example 2: Vertically opposite angles and revolutions

Worked example

Find the value of each pronumeral. Give a reason.

Try it in your head first, then show one step at a time.

  1. aa: which fact?
    vertically opposite angles are equal, so a = 52
  2. b: which fact?
    angles on a straight line add to 180°
  3. Solve for b
    b = 180 − 52 = 128
  4. bWhich angle sum?
    angles in a revolution add to 360°
  5. Equation
    c + 90 + 140 = 360
  6. Solve
    c = 360 − 230 = 130

Example 3: Angles written with algebra

Worked example

Find the value of x, then the size of each angle.

Try it in your head first, then show one step at a time.

  1. 1Which angle sum?
    angles on a straight line add to 180°
  2. 2Equation
    3x + 2x = 180
  3. 3Collect like terms
    5x = 180
  4. 4Solve
    x = 1805 = 36
  5. 5Each angle, and check
    3 × 36 = 108°,  2 × 36 = 72°,  108 + 72 = 180 ✓
